1. Problem Definition
- Business Problem: Customers leaving (churning) reduces revenue and growth potential.
- Objective: Build a predictive model to identify customers at risk of churn.
- Outcome: Enable proactive retention strategies (discounts, loyalty programs, personalized outreach).
2. Success Metrics
We’ll track both technical and business outcomes:
- Technical Metrics:
- ROC‑AUC ≥ 0.80 (strong classifier performance)
- F1‑Score ≥ 0.70 (balanced precision/recall)
- Business Metrics:
- Reduce churn rate by at least 10%
- Increase retention campaign ROI (e.g., every $1 spent saves $3 in CLV)
3. Project Scope
- Data Source: Telecom churn dataset (Kaggle or simulated if needed).
- Model Types: Logistic Regression (baseline), Random Forest, XGBoost.
- Deployment: Simple API + web demo for churn prediction.
- Deliverables: GitHub repo, technical documentation, business report, presentation.
